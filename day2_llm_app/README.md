# Day 2: AI Resume & Career Match Analyzer

This directory contains the Day 2 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `app.py`: Streamlit web app for Resume vs Job Description evaluation.
- `templates.py`: Structured prompt templates with JSON output schema.
- `sample_data/`: Sample candidate resume (`sample_resume.txt`) and target job description (`sample_jd.txt`).
- `reflection_report.md`: Reflection report detailing LLM app architecture and prompt tuning.

## 🚀 How to Run
```bash
streamlit run day2_llm_app/app.py
```
