# Day 3: KromaPDF AI — RAG PDF & Knowledge Search Engine

This directory contains the Day 3 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `rag_engine.py`: Document ingestion, ChromaDB vector database management, HuggingFace embeddings, and retrieval QA chain.
- `app.py`: Streamlit Chatbot UI featuring document upload, chunk size adjustment, vector DB persistence status, and expandable source page citations.
- `sample_docs/`: Sample CRISP handbook document (`ai_handbook_summary.txt`).
- `reflection_report.md`: Deep dive into RAG chunking strategies and embedding choices.

## 🚀 How to Run
```bash
streamlit run day3_rag_system/app.py
```
