# Day 5: Tool & MCP Integration

This directory contains the Day 5 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `external_tools.py`: Live Weather API (Open-Meteo), DuckDuckGo Web Search, and Calendar Meeting Invite tools.
- `mcp_bridge.py`: Model Context Protocol (MCP) standardized tool registry and schema definition layer.
- `app.py`: Streamlit multi-tab hub for standalone tool testing, MCP schema inspection, and agent assistant execution.
- `reflection_report.md`: Reflection report detailing MCP tool schema standardization.

## 🚀 How to Run
```bash
streamlit run day5_tool_integration/app.py
```
