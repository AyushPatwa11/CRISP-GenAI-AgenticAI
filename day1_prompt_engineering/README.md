# Day 1: Prompt Engineering Lab & Benchmark Suite

This directory contains the Day 1 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `prompts_dataset.json`: 20 benchmark prompts across Zero-Shot, Few-Shot, Chain-of-Thought, and Role Prompting with before/after outputs.
- `app.py`: Interactive Streamlit playground to filter, inspect, and execute engineered prompts live.
- `reflection_report.md`: Technical analysis report on prompt techniques, accuracy, and format adherence.

## 🚀 How to Run
```bash
streamlit run day1_prompt_engineering/app.py
```
