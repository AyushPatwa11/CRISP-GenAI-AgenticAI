# Day 7: Capstone Project & Viva Assessment Center

This directory contains the Day 7 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `app.py`: Master multi-page Streamlit portal hosting all 7 projects with an interactive Viva Voce prep center.
- `viva_prep.py`: Interactive Flashcard & Quiz dataset covering all 10 sample Viva questions from the CRISP handbook.

## 🚀 How to Run

streamlit run day7_capstone/app.py
