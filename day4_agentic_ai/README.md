# Day 4: CogniTrace AI — Autonomous ReAct Agent & Visual Trace

This directory contains the Day 4 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `agent.py`: Custom ReAct (Reasoning + Acting) Agent class supporting multi-tool execution and memory.
- `tools.py`: Python tools (Safe Calculator, Text Analyzer, Currency Converter).
- `app.py`: Streamlit dashboard with live visual trace logs (Thought ➔ Action ➔ Observation).
- `reflection_report.md`: Reflection report detailing agentic planning and memory loops.

## 🚀 How to Run
```bash
streamlit run day4_agentic_ai/app.py
```
