# Day 6: Industry AI Solution — Financial Filing Analyzer

This directory contains the Day 6 deliverables for the CRISP Generative & Agentic AI Program.

## 📌 Deliverables Included
- `financial_engine.py`: Corporate ratio calculation engine and LLM financial summarizer.
- `app.py`: Streamlit executive dashboard featuring Plotly balance sheet charts, ratio metrics, risk factor audits, and downloadable reports.
- `sample_reports/`: Sample 10-K quarterly report text (`sample_financial_report.txt`).
- `reflection_report.md`: Reflection report detailing domain-specific AI financial architecture.

## 🚀 How to Run
```bash
streamlit run day6_industry_solution/app.py
```
